# Results interpretation
Running `python -m experiments.run_all` creates the CSV/JSON result files.

The results are only from the demo scaffold. They can establish that the software workflow and test harness execute, not that LiteQSign, SIS aggregation, ML-KEM, AES-256-GCM, quantum resistance, or the 2025 paper's claimed performance has been reproduced.

For journal submission, replace the demo adapters, rerun all experiments, preserve raw output, document hardware and versions, and label unmeasured items as not measured.
